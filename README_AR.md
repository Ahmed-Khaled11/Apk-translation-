# صوت وترجمة — مشروع Android

هذا مشروع Android Studio (Kotlin) لتجربة ترجمة الصوت الداخلي من الإنجليزية إلى العربية.

## ما الذي يفعله؟
- يطلب إذن Android الرسمي لمشاركة/التقاط صوت التشغيل.
- يلتقط صوت الوسائط والألعاب المتوافق مع Android Audio Playback Capture (Android 10+).
- يتعرف على الإنجليزية محليًا باستخدام Vosk، ويحمل نموذجًا صغيرًا تلقائيًا عند أول تشغيل.
- يترجم الجمل النهائية إلى العربية عبر خدمة MyMemory؛ لذلك يلزم الإنترنت للترجمة.

## حدود مهمة
- ليس كل تطبيق يسمح بالتقاط صوته؛ التطبيقات التي تمنع Audio Playback Capture أو تستخدم DRM لن يظهر صوتها.
- الترجمة تظهر بعد اكتمال مقطع الكلام، وليست ترجمة كلمة بكلمة بزمن صفري.
- جودة/سرعة الترجمة تعتمد على وضوح الصوت والإنترنت وخدمة الترجمة.
- أول تشغيل يحتاج تنزيل نموذج التعرف الإنجليزي (حوالي عشرات الميجابايت).
- هذا مشروع مصدر قابل للبناء، وليس APK مبنيًا.

## البناء
1. افتح مجلد `SawtTarjama` في Android Studio حديث.
2. اترك Gradle ينزل الاعتماديات.
3. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ستجد APK في `app/build/outputs/apk/debug/app-debug.apk`.

## المتطلبات
- Android Studio حديث وAndroid SDK 35.
- هاتف Android 10 أو أحدث.


## بناء APK تلقائيًا عبر GitHub Actions (بدون Android Studio)
1. أنشئ مستودعًا جديدًا على GitHub.
2. فك ضغط `SawtTarjama-Android-Project.zip` وارفع **كل محتويات المجلد** إلى المستودع (بما فيها `.github`).
3. افتح تبويب **Actions** في المستودع.
4. إذا طلب GitHub تفعيل Actions، وافق على التفعيل.
5. افتح مهمة **Build Android APK** واضغط **Run workflow**، أو ادفع الملفات إلى فرع `main`/`master` لتبدأ تلقائيًا.
6. انتظر حتى تنتهي المهمة بعلامة نجاح خضراء.
7. افتح نتيجة التشغيل، وانزل إلى **Artifacts**، ثم نزّل `Sawt-Tarjama-APK.zip`.
8. فك ضغطه على الهاتف وثبّت `app-debug.apk`. قد يطلب Android السماح بالتثبيت من هذا المصدر.

إذا فشل البناء، افتح سجل المهمة وانسخ رسالة الخطأ لمراجعتها.
